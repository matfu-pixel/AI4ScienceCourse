## Масштабирование генеративного поиска (с. 7–9)

Авторы исследуют масштабирование генеративной рекомендательной системы PLUM на четырёх моделях Gemini-1.5 MoE: MoE-110M, MoE-370M, MoE-900M и MoE-3B (с. 7). Эксперименты проведены на производственных данных YouTube с длиной входной последовательности 1,536 токенов на 1,024 Google's v6e TPUs (с. 7). Выявлена степенная зависимость между Iso-FLOPS и training/evaluation loss для всех размеров моделей (с. 8). Оценка Recall@10 продолжает расти с увеличением вычислений, не демонстрируя признаков переобучения: MoE-110M обучался 4.24 эпохи без деградации (с. 8). Модель MoE-3B обработала лишь 0.57 эпохи из-за меньшего batch size (с. 8). Вывод: compute-optimal training требует синхронного масштабирования объёма данных и размера модели (с. 8).
