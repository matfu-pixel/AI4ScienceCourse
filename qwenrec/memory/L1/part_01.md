## PLUM: адаптация предобученных языковых моделей для рекомендательных систем (с. 1–2)

Авторы предлагают PLUM — фреймворк для адаптации предобученных больших языковых моделей (LLM) к задачам рекомендательных систем промышленного масштаба. Метод состоит из трёх этапов: токенизация предметов с помощью Семантических ID (Semantic IDs, SIDs) на базе SID-v2; дообучение (continued pre-training, CPT) на смеси предметных данных, пользовательских последовательностей и общего текста; тонкая настройка для генеративного поиска, где декодер-модель авторегрессионно генерирует SIDs рекомендуемых предметов. Эксперименты на внутренних видео-данных YouTube показывают существенное улучшение качества извлечения по сравнению с производственной моделью на больших embedding-таблицах. При этом PLUM использует Transformer с 100× плотными параметрами больше, но общая стоимость обучения сопоставима благодаря более быстрой сходимости. Наблюдается эффективное масштабирование: качество растёт вплоть до Mixture-of-Experts (MoE) модели с более чем 900M активированных параметров (около 4.2B параметров в целом). Фреймворк развёрнут в продакшене YouTube.
