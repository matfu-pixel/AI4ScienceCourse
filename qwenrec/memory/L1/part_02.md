## Semantic IDs и Continued Pre-training (с. 3–4)

Метод PLUM формирует семантические идентификаторы (SID) через RQ-VAE с мульти-модальным слиянием эмбеддингов (с. 3), многоуровневыми кодовыми словарями кардинальности 2048/2^(level-1) (с. 3) и прогрессивным маскированием (с. 3). Контрастная потеря по со-встречаемости L_con = −Σ exp(sim(p_i, p_i+)) / Σ exp(sim(p_i, p_j)) (с. 3) привязывает SID к поведению пользователей, формируя семантические кластеры из совместных просмотров (с. 3). Итоговая функция потерь L = L_recon + L_rq + L_con (с. 4) обучает квантователь на 1 млн шагов (с. 4) с размером батча 16 (с. 4), что составляет около 260 млрд токенов (с. 4) из смеси пользовательских данных и метаданных видео (по 50%) (с. 4). Продолженное предобучение (CPT) обеспечивает семантическую привязку SID к текстовым токенам базовой языковой модели (с. 4). Модель сохраняет способность к few-shot обучению и генерации свободного текста (с. 4).
