# AGENT.md — QwenRec

## Цель проекта

Этот проект является подпроектом будущего проекта про фундаментальную модель
для рекомендательных систем. Цель проекта показать, что инициализация рекомендательного
трансформера весами предобученной LLM (Qwen3-0.6B-Base) улучшает качество на задаче
Next Item Prediction против случайной инициализации.

## Данные и материалы

- `data/` — исходные данные это датасет [Yambda](https://huggingface.co/datasets/yandex/yambda):
  - `listens.parquet` — 50m прослушиваний музыки пользователями.
  - `embeddings.parquet` — контентные эмбеддинги для каждого item_id.
- `paper/` — здесь будет лежать финальная статья и исходники. Пока что в `tg_posts.md` лежат
предварительные результаты, которые получались независимо на немного другом сетапе.
- Исходные данные не изменять; производные файлы — в отдельных папках.

## Как работать

- Код — в `src/`, запускать перед тем, как сообщать результат.
- Каждый вывод сопровождается способом его проверки.
- Сводки и заметки для следующих сессий — в `memory/`.

## Журнал

- После каждой задачи — запись в `diary.md`: дата, запрос, что сделано,
  результат, точка проверки, итог проверки. Старые записи не менять.
